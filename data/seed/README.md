# Fictional ACL fixtures

Generated by `python -m scripts.make_seed`. Three tenants each have five demo users
and six documents spanning public, internal and confidential classifications.

The intentionally public demo password is `demo-password`. It is not a production
secret; users.json stores independently salted PBKDF2 hashes. Do not use these accounts
or credentials in production. Regeneration refreshes salts without changing ACL facts.

Role and explicit-user grants are the permission ground truth. `public` still requires
tenant equality and a grant. Admin has no implicit bypass. Unique marker strings are
fictional evidence designed for leakage assertions, not actual confidential data.
