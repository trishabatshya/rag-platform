# Northwind Cloud product FAQ

Northwind Cloud is a fictional managed workspace for publishing internal documentation
and running scheduled automation jobs. A workspace contains projects; each project has
documents, automation jobs and an activity log. Northwind Cloud does not sell virtual
machines or provide a cryptocurrency exchange.

Workspace names must contain between 3 and 40 characters. Workspace names can use
letters, digits and hyphens. A project can be archived without deleting its documents.
Archived projects are read-only and their scheduled automation jobs stop running.

The web console supports the latest two stable releases of Edge, Chrome and Firefox.
The command-line tool is named nwctl. Northwind Cloud's documentation examples use
UTC for every scheduled job, regardless of the user's browser timezone.
