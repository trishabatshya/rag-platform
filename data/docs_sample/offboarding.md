# Cancellation and workspace closure

Only a workspace owner can cancel a subscription. Cancellation stops renewal and
leaves the workspace readable until the current paid period ends. After the paid
period, a cancelled workspace remains available for export for 30 calendar days.

Permanent workspace deletion requires typing the workspace name and confirming by
email. Live documents are deleted within 7 calendar days of confirmation. Backup
copies expire according to the 30-day backup retention schedule. API keys are revoked
immediately when permanent deletion is confirmed.

An owner should export documents before confirming deletion. Cancelling a subscription
does not automatically request a refund, transfer ownership or delete the workspace.
Deleting a user account alone does not cancel subscriptions owned by that user.
