# Security overview

Northwind Cloud encrypts customer documents at rest with AES-256. Connections use TLS 1.2
or later. Staff access to production requires hardware-backed multi-factor authentication
and a recorded support or incident ticket. Customer passwords are never stored in plaintext.

Workspace owners can require multi-factor authentication for all members. Security audit
logs are retained for 180 days on Team. Report suspected vulnerabilities to
security@northwind.example; the security team acknowledges reports within 2 business days.

This fictional service makes no SOC 2 certification claim. Security overview facts are
provided for retrieval experiments. SAML single sign-on is available on Team and Enterprise;
the Pro plan supports password and multi-factor authentication only.
