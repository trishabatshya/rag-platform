# Regional hosting

Northwind Cloud offers hosting in Frankfurt (eu-central) and Virginia (us-east).
Workspace owners choose the hosting region during onboarding. Document data and backups
stay in the selected region. Account email addresses and billing metadata are stored
in a separate global account system.

A workspace's hosting region cannot be changed after creation. To move regions, create
a new workspace in the target region, export documents from the old workspace and
import them into the new one. API keys must be recreated in the new workspace.

The billing address controls the refund policy; the hosting region does not control it.
For example, an EU customer hosting in Virginia follows the EU refund policy. Hosting
is not currently available in Singapore, Sydney or Mumbai.
